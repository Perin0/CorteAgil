Todos os exercícios anteriores foram executados utilizando a sintaxe moderna do angular, nesse caso irei citar diferenças entre as sintaxes

  • No for, com obrigatoriedade do parâmetro 'track', a expressão é resolvida diretamente no HTML sem métodos extras no TypeScript, entregando algoritmos mais eficientes
  • O bloco empty agora permite uma maneira nativa e integrada ao bloco for, de verificar o preenchimento de um elemento
  • Sintaxe moderna permite seguir a lógica de programação comum de outras linguagens amplamente usadas
